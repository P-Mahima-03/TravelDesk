# TravelDesk

An advanced Travel Agency Management and Online Booking Platform built with React, Spring Boot, and MySQL.

## Project Overview

TravelDesk is a web-based travel agency application that helps customers explore destinations, discover travel packages, search flights and hotels, make bookings, manage trips, and access travel-related services.

The platform also provides dedicated workspaces for administrators, travel agents, and customer support staff.

## User Roles

- **ADMIN** – Manages users, destinations, packages, bookings, and platform analytics.
- **TRAVEL_AGENT** – Manages travel enquiries, customer bookings, and trip arrangements.
- **CUSTOMER** – Explores travel options, makes bookings, manages trips, and submits reviews.
- **SUPPORT_STAFF** – Handles customer support tickets and service requests.

## Development Approach

TravelDesk follows a modular monolith architecture with a React frontend, Spring Boot REST backend, and MySQL database.

Development is organized into small, focused GitHub Pull Requests. Each feature should be implemented, tested, reviewed, and merged independently after its dependencies are available.
